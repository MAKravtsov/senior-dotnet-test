## Архитектура

Проект состоит из двух отдельных сервисов Bot и AIAgent, которые обмениваются сообщениями через шину (RabbitMQ + MassTransit).

1) Bot — получает сообщения от пользователей через Telegram и публикует запросы в шину (сообщения `BotAnswerRequested`).
2) AIAgent — потребляет `BotAnswerRequested`, формирует ответ (локальный поиск по базе знаний или внешний LLM) и публикует `BotAnswerReady`.
3) Bot - получает от AIAgent ответ `BotAnswerReady` и отправляет его в польваотелю

Шина сообщений делает архитектуру гибкой: можно запускать несколько экземпляров AIAgent для горизонтального масштабирования, либо заменить стратегию ответов, не затрагивая бота.

## Проекты в решении

Репозиторий содержит несколько сборок:

- `Bot` — основной Telegram-бот. Регистрация Telegram-клиента, приём апдейтов, публикация запросов в шину и отправка ответов пользователям.
- `AIAgent` — агент, который потребляет входящие запросы и формирует ответы. Внутри реализуется интерфейс `IAiResponder` с несколькими реализациями (Search/Горизонтальный поиск по файлу, OpenAI, Gemini).
- `RabbitMq` — вспомогательная библиотека/пакет с расширением DI для быстрой настройки MassTransit + RabbitMQ (чтение конфигурации, вызов `cfg.ConfigureEndpoints(context)` и т.п.).
- `Messages` — проект с контрактами сообщений (DTO): `BotAnswerRequested`, `BotAnswerReady` и т.д. Эти контракты публикуются в шину и используются обоими сторонами.

## Запуск

Общие требования:

- .NET 8 SDK установлен.
- Запущенный RabbitMQ (локально или удалённый). Для удобства можно использовать официальный Docker-образ RabbitMQ с включённым Management UI (порт 15672).

Примеры команд (запускать из корня `Src` или по отдельности из папок проектов):

```bash
# Собрать всё решение
dotnet build

# Запустить бота (в папке Src/Bot)
cd Src/Bot
dotnet run

# Запустить ai-агент (в папке Src/AIAgent)
cd Src/AIAgent
dotnet run
```

Чтобы случайно не закоммитить секьюрные данные, рядом с обычной конфигурацией можно положить файл `appsettings.private.json`. Этот файл добавлен в `.gitignore`, поэтому он никогда не уйдет в глобальный репозиторий

### Бот (`Bot`)

- `Bot:BotToken` — токен вашего Telegram-бота.
- `RabbitMq` — секция с параметрами:
  - `Host` — адрес брокера (например, `localhost`)
  - `Port` — порт (обычно `5672`)
  - `VirtualHost` — виртуальный хост (обычно `/`)
  - `Username`, `Password` — учётные данные

### AI-агент (`AIAgent`)

AI агент работает по следующему алгоритму: разбивает файл на embeddings и сохраняет в опертивную память. При каждом запросе от пользователя векторным поиском подбирает контекст из кэша и передает в существующую языковую модель 

AIAgent поддерживает несколько типов ответов, выбираемых через конфигурацию `Agent:Type` (enum `ResponderType`):

- `Search` — простой векторный поиск по файлу.
- `Gemini` — интеграция с Google Gemini AI (требуется соответствующий ключ `GeminiApiKey`). Этот код присутствует, но поведение не гарантировано и не было полноценно протестировано в этом репозитории.
- `OpenAI` — интеграция с OpenAI (API key в конфиге `OpenAIApiKey`). Также не было полноценно протестировано здесь.


- `RabbitMq` — секция с параметрами:
  - `Host` — адрес брокера (например, `localhost`)
  - `Port` — порт (обычно `5672`)
  - `VirtualHost` — виртуальный хост (обычно `/`)
  - `Username`, `Password` — учётные данные
